# Governance-Dashboard
Единый дашборд зрелости Data Governance: метрики по каталогу, качеству, PII, доступам, compliance.


Единый дашборд зрелости Data Governance:
- Модель зрелости 5 уровней (Initial → Optimized)
- Radar-диаграмма по 7 измерениям
- Scorecard по каталогу/качеству/privacy/lineage
- Автоматические рекомендации
- Отчёт в JSON

## Запуск
```bash
streamlit run app.py
```
